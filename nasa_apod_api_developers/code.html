The Endpoint

GET https://api.nasa.gov/planetary/apod

Query Parameters

api_key

Required string

Valid API key for authentication. Default: DEMO_KEY

date

Optional string (YYYY-MM-DD)

The date of the APOD image to retrieve. Defaults to today's date.

concept_tags

Optional boolean

Returns relevant keywords for the image when set to True.
